# Natural Language Processing (NLP) Experiments

This repository contains practical implementations of Natural Language Processing (NLP) concepts using Python. It includes text preprocessing, text vectorization, word embeddings, text similarity, classification, sentiment analysis, topic modeling, information extraction, information retrieval, and deep learning models.

## 📚 Experiments Included

| No. | Experiment | Description |
|---|---|---|
| 08 | Bag of Words (BoW) | Text vectorization using the Bag of Words approach. |
| 09 | TF-IDF Implementation | Implementation of TF-IDF and comparison with BoW. |
| 10 | N-Gram Model | Generation of Unigram, Bigram, and Trigram models from a corpus. |
| 11 | Cosine Similarity | Computation of cosine similarity between text documents. |
| 12 | Word2Vec Embeddings | Word embeddings using Gensim on a custom corpus. |
| 13 | GloVe Embeddings | Loading GloVe embeddings and representing words as vectors. |
| 14 | Word Mover's Distance (WMD) | Measuring semantic similarity between text documents. |
| 15 | Text Classification | Text classification using Naive Bayes, SVM, and TF-IDF. |
| 16 | Sentiment Analysis | Sentiment analysis using TextBlob and VADER. |
| 17 | Topic Modeling using LDA | Discovering topics using Latent Dirichlet Allocation. |
| 18 | Topic Modeling using LSA | Topic modeling using Latent Semantic Analysis. |
| 19 | Opinion Mining | Analyzing opinions in product and service reviews. |
| 20 | Information Extraction | Extracting information from structured and unstructured documents. |
| 21 | Information Retrieval | Building a document retrieval system with TF-IDF ranking. |
| 22 | Sequence Classification | Sequence classification using RNN and LSTM with Keras and TensorFlow. |
| 23 | Attention Mechanism | Implementing a basic custom attention mechanism. |

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd <your-repository-folder>
```

Replace the placeholders with your GitHub repository URL and folder name.

### 2. Install Dependencies

Make sure Python is installed, then run:

```bash
pip install jupyter numpy pandas scikit-learn nltk spacy gensim textblob vaderSentiment matplotlib tensorflow
```

Some notebooks may require additional datasets, language models, or pretrained word embeddings.

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required `.ipynb` file and run the cells sequentially.
